Black-Box Architecture Specification

This project exposes automated ingestion endpoints for any external OCR, LLM, or microservice worker program to handle the document conversion:

1. Polling Pending Documents Endpoint:
GET /api/documents/pending/
2. Submitting Converted JSON & SQL Data:
POST /api/documents/{doc_id}/submit-result/
Content-Type: application/json
{"status": "completed", "extracted_text": "...", "json_output": {...}, "sql_output": "..."}
When files are submitted with "Auto-Convert Now", the built-in BlackBox simulation engine immediately extracts structured line items, calculates financial sums, and emits SQLite / PostgreSQL compatible SQL schema and insert queries.
